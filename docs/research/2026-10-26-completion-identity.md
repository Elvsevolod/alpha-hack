# Единая идентичность рецепта при завершении ML-исследования

Продолжение общего аудита агента после `b627bd2`. Предыдущий goal-turn дал прогресс: сохранены результаты 27 ML/DL arms и три исправления пути данных. Общая цель лучшего автономного агента остаётся активной; эти свидетельства не доказывают её полного достижения.

## Основание и воспроизведение

ТЗ требует самостоятельного выбора решения и готового CSV за общий срок задачи. Действующий проектный контракт дополнительно требует учитывать весь граф control/refit, переиспользовать проверенные результаты и не повторять неизвестные исходы. Матрица исходных требований находится в `2026-10-26-agent-path-audit.md`; текущий путь завершения описан в `docs/qa_section4.md`. Новое семейство моделей для исправления не требуется.

`Controller._prepare_finalist()` уже нормализовал старый `frozen_pipeline` через `PipelineSpec`: отсутствующие поля по умолчанию не меняли исполнимую конфигурацию. Но `completion.estimate()` сравнивал сырые JSON-digest. Поэтому один и тот же корректный результат исполнитель принимал без обучения, а прогноз помечал неподготовленным, заново резервировал время/диск и мог исключить доступного финалиста до control. При чтении старого worker manifest вместо текущей policy расходился также hash для фактически измеренных `completion_costs`: наблюдение о дорогом refit не уточняло прогноз.

Воспроизведение до фикса: **3 failed, 6 passed** в `completion_identity_before_v2.xml`. Используются собственные синтетические артефакты; реальные API и скрытые метки не задействованы. Первоначальный черновик fixture разделял mutable dict между policy и saved recipe; это исправлено до указанного подтверждённого воспроизведения, а первоначальный запуск сохранён отдельно в outputs и не считается четвёртым дефектом продукта.

## Исправление

Прогноз нормализует исходный и сохранённый рецепты через тот же `PipelineSpec`. Известные non-default параметры и выбранные эпохи сохраняются. По этой канонической идентичности он сопоставляет фактические наблюдения стоимости и распознаёт готовые фазы. Невалидный сохранённый рецепт не считается готовым.

Проверки наборов строк и хешей файлов сохраняются. Изменение параметра, иной row hash, повреждённый файл и malformed recipe отклоняются. Неизвестная/неудачная попытка не запускается повторно. Произвольные старые хеши без восстановимого рецепта не объявляются эквивалентными; их происхождение не угадывается.

## Проверка и границы

- Связанный набор completion/cost/final boundaries: **38 passed**.
- Итоговый новый набор: **10 passed**, частично пересекается с предыдущим; числа не суммируются как независимые тесты.
- Реальный controller lifecycle: сначала обучена и сохранена control-модель, её JSON приведён к формату с опущенными defaults; прогноз признал фазу готовой, control worker повторно не запускался, full-train refit выполнен ровно один раз, опубликован CSV для 25 строк.
- Негативные тесты проверяют сохранение границ identity/integrity; нормализация не означает принятие любой конфигурации.

Это исправление корректности бюджета и восстановления. Прирост RMSE/Macro F1 либо превосходство автономного Qwen не измерялись. Рецепты RealMLP/деревьев, прошлые freezes, main и конкурсный ZIP не изменяются. Путь PyTorch не расширяется. Реальных запросов к API организаторов нет.

Машиночитаемые свидетельства: `research/agent_path_audit_20261026/completion_identity.json`. Первичные JUnit остаются в ignored outputs. Продолжение цели требует дальнейшей проверки решений/передачи данных агента и сопоставимого живого качества; данное исправление не закрывает всю цель.
