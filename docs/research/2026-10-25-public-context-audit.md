# Последний main, контекст и публичная задача WDBC

## Версии и граница проверки

После `git fetch` последний `origin/main` — **1c463e90b081e963241e46496173de020bfaba0f**. Исследовательская ветка перед этой проверкой — **4d8e349**, поверх него. Два прогона разделены: первый проверяет main с предыдущими исследовательскими изменениями, второй — отдельный неизменённый снимок точного main. Исполняемые исходники снимка сравнены с `dist/solution_v101.zip`: **80 файлов, ноль различий и пропусков**. Это проверка исполнения исходников, а не новый запуск ZIP на платформе организаторов.

Последний большой main-коммит содержит версии v073–v101 и изменения AutoML/OOF. Предыдущий исследовательский коммит добавляет прежде всего dev-инструменты, общие помощники, evidence и инструкции. Новая residual calibration не становится от этого автоматически выбираемым typed-инструментом агента. Успех reference-эксперимента не означает успех автономного цикла.

Docker недоступен: отсутствует его daemon socket. Выполнен native Python-прогон с разрешёнными ML-зависимостями, штатными ограничениями worker, Qwen организаторов, 2 CPU, 4096 МБ и 600 секундами; до десяти вызовов модели. Защиты worker проверялись runtime. Точной контейнерной и платформенной эквивалентности не заявляем.

## Данные и сильный ориентир

[UCI WDBC](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic): 569 наблюдений, 30 вещественных признаков, CC BY 4.0. Авторы: Wolberg, Mangasarian, Street и Street; DOI 10.24432/C5DW2B. Использована распространяемая sklearn копия; во время решения агент не скачивает данные или документацию. ID добавлены как номера строк, а не признаки.

Внешнее разделение 80/20 стратифицировано, seed 42: 455 train и 114 test. Внешние метки, параметры ориентира и его прогноз лежат в соседнем evaluation-каталоге и не передаются агенту. Нативный harness не заменяет OS-изоляцию файлов. В условиях задачи указаны метрика, классы и выход; подсказки о модели нет.

Ориентир выбран только по четырёхкратной train-CV среди 22 конфигураций SVM, логистической регрессии и ExtraTrees. Победитель — **StandardScaler + RBF SVC(C=10, gamma=0.01)**; train-CV Macro F1 0,976264. Преобразование масштаба входит в Pipeline и учится внутри каждого fold, как рекомендует [документация sklearn](https://scikit-learn.org/stable/common_pitfalls.html). Это сильный локальный ориентир, не заявка на глобальный SOTA и не перенос чужой опубликованной цифры на наше разбиение.

## Переполнялся ли контекст

**Нет подтверждённого переполнения или output truncation.** Максимальный server prompt среди измеренных исследовательских запросов: **29 748 токенов** в ветке и **32 460** в main. Локальный guard использует консервативную оценку по UTF-8-байтам с резервом; её нельзя выдавать за фактический tokenizer usage или подтверждённое окно провайдера.

Статический overhead большой: схемы инструментов занимают **47 459 байт canonical JSON** (около 52 КБ при обычной JSON-сериализации) и больше половины первых исследовательских запросов. Полный prompt растёт также за счёт истории, профиля и локальных references, но наблюдавшиеся отказы вызваны аргументами/форматом, а не context limit.

Суммарный usage ветки: 221 702 prompt + 26 091 completion tokens; main: 252 145 + 43 810. В completion входят reasoning tokens, соответственно 21 598 и 38 826. Это сумма повторных запросов, не размер одного контекста. Время модели включает сеть/очередь и не равно чистому thinking time.

Проверен дешёвый вариант дополнительного удаления schema titles. **Он не уменьшил рабочий payload**: существующий Transport уже удаляет эти аннотации. Избыточная реализация удалена; уменьшение контекста не заявляется. Сокращение повторяющихся native-схем требует отдельного дизайна и проверки качества, а не механического удаления доступных полей.

## Подтверждённые затыки и исправления

| Наблюдение | Классификация | Изменение |
|---|---|---|
| Ветка отправила XGBoost `lambda`, целиком отклонён пакет экспериментов | Несовпадение upstream-алиаса и typed whitelist | Нормализация lambda/reg_lambda, alpha/reg_alpha, eta/learning_rate, min_split_loss/gamma; конфликтующие значения отклоняются |
| Агент назвал random exact-feature stress временными окнами и изменением подмножества признаков | Ошибка интерпретации + неоднозначное историческое имя temporal_stability | В отчёт и короткую память добавлены split_strategy, varied_axis=rows_not_features, temporal_order_required и основание группировки; старое имя сохранено для совместимости |
| finish был отклонён из-за несовпадения свободных skipped_directions с точными action IDs | Скрытая методическая квота | Неиспытанные карточки теперь advisory; завершение по-прежнему требует измеренных результатов текущего протокола и проходит проверки финализации/компонентов |
| Агент трактовал одинаковый агрегированный F1 как доказательство одинаковых ошибок и непреодолимого потолка | Неподтверждённый вывод | В всегда передаваемой research policy явно запрещён такой вывод; family diversity больше не задаёт обязательную очередь |
| main вызвал read_run_records без ids/source | Ошибка аргументов; runtime правильно отказал | Зафиксировано как оставшийся interface gap: часть межполевых условий есть в Pydantic, но не выражена структурно в JSON Schema |
| main попытался удалить компоненты родителя без changed_fields | Сработавшая защита, не дефект | Ограничение сохранено; его нельзя ослаблять ради успешного прогона |

[Официальные параметры XGBoost](https://xgboost.readthedocs.io/en/stable/parameter.html) описывают использованные алиасы; равенство реальных прогнозов проверено на установленном XGBoost 2.1.4. Нормализация не разрешает произвольные параметры и не меняет контролируемые CPU/device настройки.

Новая логика finish допускает более раннюю остановку — это сознательное изменение исследовательской политики, а не гарантия роста F1. Проверка через настоящий Controller подтверждает: пустые result_ids отклоняются, допустимый finish замораживает поиск, контроль до отдельной финализации не открывается. Неиспытанные альтернативы и отсутствие доказанной оптимальности сохраняются в readiness.

## Решения агента и недостающие возможности

Оба прогона исследовали главным образом варианты деревьев. В ветке агент восстановился после несовместимого пакета; main дополнительно запросил fit-inner confusion. Масштабированная гладкая модель не была проверена, хотя такая гипотеза уместна для небольших числовых данных с разными масштабами. Неиспытанность не доказывает непригодность.

SVC отсутствует среди быстрых native action cards; разрешённая sklearn-реализация доступна через отдельно проверяемый custom-путь. Поэтому автоматическое достижение результата внешнего SVM-ориентира не гарантируется самим наличием библиотеки в контейнере. Следующий содержательный тест — доступность и самостоятельный выбор таких представлений/моделей при корректной стоимости, а не ещё один локальный перебор деревьев.

Изменённые правила ещё **не проходили новый платный A/B-прогон**. Для них подтверждены конкретные offline-регрессии, не улучшение предсказаний.
