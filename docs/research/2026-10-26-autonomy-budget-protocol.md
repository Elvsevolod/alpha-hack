# До запуска: самостоятельный эксперимент после исправления preview и бюджета

Следующий отдельный live run проверяет текущую ветку после 8dc318d. Расширен только development driver: max-calls/max-candidates задаются CLI и сохраняются в freeze; прежние defaults 6/2 сохранены. Production-лимиты не вводятся. Runtime до старта фиксируется коммитом и не меняется во время исполнения.

Заранее заданы 900 s, CPU1, 3072 MiB, max-calls=12, max-candidates=2, seed42; знакомая организаторская задача многоклассовой классификации. Не задаются модель, рецепт, гиперпараметры, research focus или generation overrides. Используется тот же разрешённый organizer endpoint и собственный полный train→CSV цикл. Сравнение с прежним 600 s / 6 calls не изолирует эффект отдельного исправления; оно отвечает, способен ли текущий агент провести эксперимент с большим development-запасом.

Наблюдаемые критерии: принятая команда Qwen действительно запускает хотя бы один завершённый research candidate; его effective recipe соответствует выбранному; сравнение идёт внутри fit/research validation; финализация сохраняет исходный deadline, проходит control/full refit и публикует полный CSV с правильными ID/метками. Программные baselines и controller fallback не засчитываются как самостоятельный выбор. Preview/read/успешный CSV без кандидата не засчитываются как автономное исследование. Частичное или неудачное обучение описывается отдельно.

Показатели качества, candidate scores, внутренний control, full wall/CPU/RSS и расходы API публикуются независимо от знака результата. Уже виденные organizer control-строки не являются новым слепым контролем; внутренний control может выбирать финалиста. Нового независимого quality gain этот run не доказывает. Отдельные сравнения ML/DL-рецептов и отрицательный результат RealMLP-TD-S не переобучаются и не подменяются этим опытом.

Перед стартом проверить текущие ML/API-процессы; чужие серии не останавливать. alpha-api-limits before/after сохраняет driver; after только после terminal child. Не увеличивать параметры в ходе run, не возобновлять прошлые неизвестные запросы. Не запускать рядом другие тяжёлые проверки. При ошибке — фиксировать её и оставшийся результат. Среда native development, не официальный Linux/8 CPU/32 GB/3 h. Упаковка/production/ZIP не меняются. Общая цель остаётся активной независимо от исхода одного ограниченного опыта.
