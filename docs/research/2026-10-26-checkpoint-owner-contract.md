# Граница выбора итераций для custom и AutoML

При проверке путей передачи PipelineSpec обнаружено, что checkpoint_counts не имел проверки владельца, уже существующей для early_stopping_rounds. Через run_custom_experiment параметр доходил до execute_experiment: проверены отсутствие engine, явные direct и custom. Контроллер нормализует такой эксперимент в custom.

TransformerPipeline сначала обучает преобразователь / строит cross-fitted матрицу на текущем fit, затем передаёт её DirectPipeline. Последний делит уже преобразованную матрицу для выбора checkpoint. Это не независимо вложенное обучение преобразователя внутри каждого checkpoint-fit; такое разбиение нельзя считать подтверждённой внутренней проверкой всей процедуры. Это вывод из порядка операций, а не измеренный размер смещения метрики. Также AutoML-адаптеры принимали checkpoint_counts без подтверждённой реализации этого выбора; direct ridge достигал бы позднего отказа о неподдерживаемом семействе.

Добавлена ранняя incompatibility checkpoint_selection_requires_direct_or_optuna_boosting. Допустимы только direct/Optuna и четыре семейства из training_schedule.ITERATION_PARAMETER: LightGBM, XGBoost, CatBoost, HistGradientBoosting. Описание поля сообщает ограничение агенту. Для custom с пустым checkpoint_counts путь сохранён. Поддержка независимого вложенного custom checkpoint search этим изменением не вводится.

До исправления 8 failed / 2 passed, XML outputs/checkpoint_owner_20261026/before.xml. Три Controller-проверки устанавливают sentinel на выполнение кандидата и проверяют отказ до выполнения, отсутствие расхода candidate_count, неизменность опубликованного CSV и закрытый control. Пять проверяют неподдерживаемые сочетания. После исправления положительная матрица расширена до всех четырёх семейств и обоих поддерживаемых движков.

Связанные проверки реального выбора итераций, замороженного replay, final-label selection и OOF inverse прошли: 35 passed, outputs/checkpoint_owner_20261026/after.xml. В этом запуске матрица владельцев ещё содержала первоначальные два положительных случая. Расширенная матрица вместе с существующим custom save/load/control/full-refit/CSV тестом: 18 passed за 41,60 s, outputs/checkpoint_owner_20261026/custom_boundary.xml. Запуски пересекаются, их нельзя складывать как уникальные проверки.

Все проверки офлайн, без Qwen и без открытия новых контрольных метрик. Исправление улучшает корректность допуска и исключает неподдерживаемые попытки, но не доказывает рост качества или улучшение платформенного балла.
