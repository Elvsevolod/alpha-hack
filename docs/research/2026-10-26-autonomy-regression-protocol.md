# До запуска: перенос автономного исследования на регрессию

После классификационного опыта на d0bcb7f проверяется отдельная знакомая задача организаторов «Энергопотребление зданий». Исходное task.md повторно сверено: target site_eui, 53 308 train / 22 449 test, RMSE в исходных единицах. Погода дана за тот же наблюдаемый год; это не задача прогнозирования до начала года. Year_Factor — анонимизированный код периода, id не объявлен building ID; новая постановка forecasting/entity split вручную не вводится.

Заранее фиксируются те же development пределы, что в предыдущем большем опыте: 900 s, CPU1, 3072 MiB, max-calls=12, max-candidates=2, seed42. Модель, гиперпараметры, transforms, research focus и generation overrides не задаются. Источники, driver, corpus и пять входных файлов хешируются до запуска; runtime не меняется до terminal process. Не переносится выбранный для классификации class_weight-рецепт и не задаётся ожидаемое направление регрессионного улучшения.

Критерии раздельные: Qwen сам выбирает и завершает хотя бы один research candidate (baseline и controller fallback не считаются); effective recipe соответствует принятой команде; fit-only transforms/stopping/HPO не используют control/test; финализация сохраняет deadline и публикует full-refit CSV с правильными ID, порядком и конечными числовыми значениями. Улучшение RMSE проверяется относительно стартовой модели этого run, с независимым пересчётом сохранённых прогнозов. Неудачные/частичные кандидаты и их стоимость не скрываются. Успех автономного действия, интеграция и качество — отдельные результаты.

Control уже знаком по проекту, его метрики не объявляются новым слепым подтверждением или независимой репликацией. До прямой проверки совпадения строк нельзя сравнивать его с контрольными цифрами авторской RealMLP/сильного ансамбля серии. Этот run не является новым равнобюджетным сравнением деревьев/сети/смеси. Один seed/разбиение не доказывает универсальность; отрицательный результат сохраняется как отрицательный.

Перед стартом проверить текущие процессы, не мешать чужим сериям; alpha-api-limits before/after сохраняет driver. After — только после фактического завершения/ошибки/отмены; старые неизвестные запросы не возобновлять. Параллельные тяжёлые испытания не запускать. Среда native development, не официальный Linux / 8 CPU / 32 GB / 3 h. Production/ZIP/зависимости не расширяются. Положительный исход одного опыта не завершает общую цель.
