## Условия

Одинаковые подготовленные данные с SHA, seed 42, Qwen `qwen/qwen3.8-27b`, максимум 10800 секунд, worker 7 CPU / 28000 MB. Дополнительные денежные ограничения, лимит 10 генераций и четырёх кандидатов отменены пользователем. Реальный дневной лимит ключа и ресурсы ТЗ сохраняются. Резерв финализации не является квотой исследовательских методов.

Новые задачи получают чистые каталоги из пяти файлов; прежняя `.agent_work` не переносится. Память относится к экспериментам внутри одной задачи. Восстановление прежнего запуска не является обязательным конкурсным этапом.

Происхождение данных, лицензия, правила подвыборки и SHA исходных архивов/пяти подготовленных файлов сохранены в [манифесте](2026-10-26-research-memory-datasets.json). Живой harness проверяет уже подготовленный cache `outputs/eda_autonomy_20261024`, затем экспортирует runtime из Git и копирует только разрешённые файлы. Сам cache в Git не поставляется: для повтора из чистого клона эти материалы нужно подготовить отдельно и сверить SHA. Офлайн-тесты не зависят от этого cache.

ТЗ: страницы 7 и 17 в `research/2026-10-20/evidence/case_pdf_extracted.txt`. Три часа, 8 CPU / 32 GB, автономность и итоговый файл — требования организаторов. Разбиение на модули, 7 CPU / 28 GB, SQLite-журнал, проекции памяти и текущая classical-only стратегия — инженерные решения проекта.

Живые запуски последовательные. Одновременно на общем хосте выполнялись офлайн-проверки; это ограничивает интерпретацию времени как контролируемого performance-бенчмарка. Нативный локальный запуск не подтверждает Docker-приёмку или точное соответствие всего окружения платформе. Позитивные интеграционные проверки AutoGluon/LightAutoML, требующие отсутствующих локально зависимостей, не засчитываются как прошедшие. Docker daemon недоступен.
