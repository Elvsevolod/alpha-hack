# Дополнительные решения: нейроансамбли, иерархия и другие функции потерь

25 октября 2026. Продолжение [исследования по литературе](2026-10-25-literature-results.md). Новые источники ниже изучались при разработке; в конкурсный runtime интернет и скачивание моделей не добавлялись. Результаты — reference-эксперименты, а не оценка самостоятельных решений Qwen.

|---|---|---|

Официальные модули TabM требуют дополнительных библиотек для embeddings. Они не устанавливались и не вендорились. Использована самостоятельная реализация идеи MiniEnsemble без embeddings и готовых весов. Для разработки установлен **разрешённый организаторами PyTorch 2.5.1**; исходный `requirements.txt` не изменялся. Установка выполнена до эксперимента, код решения при исполнении ничего не устанавливает.

## Протокол и результаты

Сохраняются прежние разбиения: для регрессии переходы 1–2 → 3 и 1–3 → 4; для классификации — основной fit и две взаимодополняющие группы calibration/selection. Совпадающие входные строки классификации не разделяются между этими частями. Рецепт, веса и правила решения выбираются до повторной оценки контроля.

**Контроль периода 5 и классификационные контрольные группы уже использованы раньше. Все оценки ниже — повторный аудит, а не свежий слепой тест.** Внешние test-метки не использовались. Базовый коммит сравнения — `d9c947c`.

| Подход | Результат | Решение |
|---|---|---|
| Предыдущее регрессионное решение | RMSE периода 5 **39,0361** | Сохранено |
| Смесь Tweedie/Gamma, веса 0,75/0,25 | Среднее двух ранних RMSE **46,2758**; период 5 **39,7481** | Не заменяет предыдущее решение |
| TabM-mini-style отдельно | Ранние RMSE **53,3932 / 41,8913**, среднее **47,6422** | Не лучший одиночный рецепт; проверен также в ансамбле |
| Смесь Tweedie/TabM, веса 0,75/0,25 | Среднее ранних RMSE **46,1357**, период 5 **40,3593** | Не заменяет предыдущее решение |

Для регрессии проверены Poisson, Gamma и Tweedie с default `variance_power=1,5`, при остальных параметрах регуляризованного LightGBM из предыдущей серии. Их лучшие подборочные результаты не стали выигрышем на следующем проверочном году. Это ещё один отрицательный результат переноса, а не повод менять метрику после просмотра ошибок.

### TabM: технический сбой отделён от качества

Бюджетный вариант: восемь неявных участников, два общих скрытых слоя шириной 128, обучаемое масштабирование входов, отдельные выходные головы, ReLU/dropout, AdamW, до 60 эпох. Оптимизируется средний loss отдельных голов, на inference усредняются предсказания. Numeric-признаки и регрессионный таргет нормализуются по fit; категориальные кодируются по fit. Готовые веса не используются. В отличие от авторской конфигурации, нет числовых embeddings, другого полного подбора или 32 голов.

Первый worker завершился без результата; исходный return code старый logger не сохранил. Диагностический повтор с faulthandler зафиксировал **SIGSEGV, −11**, внутри большого forward-прохода при четырёх CPU-потоках PyTorch. Малые тесты проходили, поэтому их успех не считался подтверждением работоспособности на реальном объёме. Отдельный полный pytest завис и был остановлен; это сохранено как технический эпизод, не как проигрыш модели.

В одном потоке PyTorch тот же ограниченный двухэпоховый запуск прошёл, затем выполнены оба полных сравнения и refit. Первопричина native-сбоя не установлена; уменьшение потоков является рабочим ограничением этой локальной конфигурации. Не утверждается, что ошибка воспроизведётся в Linux-контейнере или что исправлена сторонняя библиотека. Нейросетевой fit ограничен внутренними 150 секундами; общий worker — 180 секундами при подборе.

### Исправлен пробел поиска ансамблей

Первые три лучших одиночных рецепта оказались одним семейством деревьев. Из-за этого прежняя эвристика не сравнивала их с менее сильной одиночной нейросетью, хотя её ошибки могли дополнять деревья.

Теперь в пул пар добавляется лучший вариант каждого `(model, alternative)` семейства, после чего смеси всё равно проверяются на development-данных. Присутствие в пуле не означает автоматическое включение в итог. Это общее исправление reference-драйвера без ветвления по названиям датасетов. Предсказания обоих ранних разбиений переиспользованы из завершённой исправленной серии с проверкой входов, индексов, конфигурации, исходников и зависимостей.

Новый поиск действительно нашёл лучший ранний ансамбль Tweedie/TabM. Но его последующий RMSE 40,3593 оказался хуже 39,0361. Само улучшение search space не является доказательством улучшения итогового предсказания; регрессионный CSV остался прежним.

### Иерархический классификатор

Первый LightGBM оценивает Normal/атака. Второй обучается только на атакующих строках и различает девять типов. На inference возвращаются мягкие оценки `P(тип)=P(атака)×P(тип|атака)` и `P(Normal)=1−P(атака)`. Истинной бинарной метки во входах нет: она выводится из разрешённого train-таргета только при обучении узла. Присутствуют все десять классов.

Проверены обычная и балансированная иерархии. Выбранный балансированный вариант объединён с прежним взвешенным XGBoost. Состав, частотная поправка и bounded class offsets выбраны по calibration/selection до повторного контроля. Метрики этих составных оценок не делают их калиброванными вероятностями.

Финальные узлы иерархии: **757 деревьев для gate и 304 для типов атак**. Число деревьев агрегируется отдельно для каждого узла; нельзя подменять его общим максимумом. XGBoost — прежние 589 деревьев. После выбора всё переобучено на разрешённых размеченных строках; test используется только для inference.

Повторная оценка: Macro F1 **0,656526** против 0,647494, прирост **0,903 процентного пункта**. Accuracy **0,808471**, Weighted F1 **0,819105** против 0,805029 и 0,816054 соответственно у предыдущего решения.

Парный bootstrap по 10 841 группе одинаковых признаков, 500 повторов, seed 42: условный процентильный 95%-интервал разницы Macro F1 **[0,001586; 0,019134]**, то есть примерно **[+0,16; +1,91] процентного пункта**. Это положительное свидетельство внутри данной выборки. Но интервал не исправляет многократный адаптивный выбор, не устанавливает независимость сетевых сессий и не гарантирует перенос на официальный hold-out.
