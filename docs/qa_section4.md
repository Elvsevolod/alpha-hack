# Проверенные расширения QA

Расширения сохранены отдельно от замороженного сравнения А/v028 и Б/v033. Реальное сравнение этих двух архивов не является проверкой итогового v038.

## Метрики

Прежние 11 метрик сохранены. В `MetricSpec.name` добавлены:

| Метрика | Направление | Определение |
|---|---|---|
| `mape` | минимум | Среднее `abs(y-p) / max(abs(y), eps64)` по строкам каждого target; доля, не проценты. Отрицательные и нулевые targets допустимы. Ошибка на нуле может быть очень большой. |
| `balanced_accuracy` | максимум | Неисправленное на случайность среднее recall по классам, наблюдаемым в `y_true`. Объявленные, но отсутствующие классы не входят в среднее. Неизвестные истинные или предсказанные метки запрещены. |

Несколько targets агрегируются равномерно либо по объявленным неотрицательным весам с положительной суммой. Значение должно быть конечным. Для вероятностей классы сначала выравниваются; метки выбираются по argmax. Неизвестное имя метрики получает `unsupported_metric` в диагностическом результате контроллера. Схема и текстовое распознавание различают accuracy и balanced accuracy.

Оценщик доверенный: сгенерированному LLM scorer не передаются закрытые метки. Новые метрики доступны direct/Optuna. Отдельные отображения FLAML/AutoGluon отклоняются до обучения, поскольку их эквивалентность здесь не проверена. Двоичные пороги не расширены на новую метрику автоматически.

## Минимальная числовая кластеризация

Отдельный контракт не содержит `targets`, классов или фиктивных supervised-меток. Вход включается явно, например:

```json
{
  "kind": "clustering",
  "train_file": "input/observations.csv",
  "test_file": "input/future.csv",
  "features": ["x", "z"],
  "id_columns": ["id"],
  "n_clusters": 2,
  "metric": "silhouette",
  "seed": 42
}
```

```text
python solution.py task.md --no-llm --clustering-contract clustering.json
```

Пути разрешаются относительно каталога задачи. Файлы должны различаться; выходные и служебные пути запрещены. Идентификаторы обязательны, уникальны внутри файла и сохраняют написание и порядок. Признаки числовые; пропуски заполняются медианой, полностью пустой признак — нулём. Далее StandardScaler и KMeans с `n_init=10`.

Детерминированная проверка использует 80% train для обучения и 20% для silhouette. Все преобразования обучаются только на обучающей части. При недостаточном числе наблюдаемых кластеров результат `undefined_silhouette`, при более 5000 проверочных строк — `limited`; подмена скрытой выборкой не производится. Замороженный рецепт заново обучается на полном train; test используется только для predict. Итоговый `submission.csv` содержит ID и `cluster`.

Обучение проходит в существующем ограниченном исполнителе без API-ключа, сети и доступа к исходным данным вне staged-копии. До публикации проверяются хеши, формат CSV и ID. Подтверждённый результат и намерение публикации сохраняются до атомарной записи; повторный вход восстанавливает CSV без нового fit. Незавершённый исход без проверенного результата не повторяется автоматически. Все фазы входят в исходный срок задачи.

Поддержка ограничена явным числовым KMeans-контрактом. Семантическая интерпретация кластеризации через Qwen и произвольные clustering-задачи не заявлены.

## Экспериментальные политики

Более строгая практическая ничья и обученное внутри fit многоклассовое правило проверены на шести синтетических случаях. Веса классов и совместимый ресемплинг остаются отдельными гипотезами. Оснований менять текущую политику ничьей не получено.

Псевдоразметка проверена отдельно на трёх синтетических случаях: разрешённый отдельный unlabeled-источник, одна итерация учитель → ученик, вес псевдометки 0,25, выбор порога только на внутренней проверке fit, происхождение каждой псевдометки и новые модели каждой фазы. Контроль замораживается до full-train refit; predict не обучает. Улучшения контроля не получено; основной маршрут не изменён.

## Уточнения итоговой поставки v038

Словарь данных допускается только из заранее проверенного структурного описания с неизменным хешем. Ошибочное семантическое предложение откатывает состояние Dataset и словарь на месте, включая аварийное прерывание. Разные роли не могут указывать на один физический файл через символическую либо жёсткую ссылку; проверка выполняется до загрузки данных.

Подготовка финалистов сохраняет время остальных уникальных узлов и полного refit. После каждого фактического выполнения прогноз пересчитывается. Нехватка диска сначала вызывает разрешённую очистку воспроизводимых артефактов, затем исключение третьего/отдельного лидера. Если baseline не помещается, сохраняется резервный CSV с явным отрицательным статусом; контроль не открывается. Неизвестные и ошибочные попытки не перезапускаются автоматически.
