# Проверка лимитов API организаторов

- Перед каждым тестовым прогоном или серией с реальным API Qwen организаторов
  и после фактического завершения, ошибки или отмены применяй скилл
  `alpha-api-limits`: [SKILL.md](skills/alpha-api-limits/SKILL.md).
- Сохраняй отдельные снимки `before` и `after` в каталоге результатов прогона.
  Сообщай остаток и изменение расхода, а при ошибке проверки — что остаток
  неизвестен. Не выводи ключ или полный ответ `/key/info`.
- Чисто офлайн-тесты без обращений к API этой проверки не требуют.
