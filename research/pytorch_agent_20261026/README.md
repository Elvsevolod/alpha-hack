# Research provenance and status

This directory preserves the earlier inspired-model screening, unfitted strong
reference templates, source snapshots and the original development-only admission
decision. The admission is historical: same-split seed replicas are not independent
transfer evidence. Subsequent frozen control checks were mixed (Adult positive,
Bank and Bike negative). It is not a production promotion certificate.

The 2026-10-25 documents copied into `docs/research` retain their original wording
and hashes as source evidence. Their implementation/status statements refer to
that earlier snapshot. Read `docs/research/2026-10-26-pytorch-conclusion.md` for the
current interpretation and `2026-10-26-agent-path-audit.md` for subsequent bug fixes.

Reference `.joblib` templates contain unfitted estimators/preprocessor definitions,
not trained weights. Split arrays reference provided training rows. Prepared input
CSVs and trained models remain in ignored `outputs/`; no external test labels are
included. The recipe benchmark is development tooling, not a task-specific branch
in the contest agent.
